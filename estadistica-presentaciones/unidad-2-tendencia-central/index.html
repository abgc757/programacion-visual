Tema 2.1

Media Aritmética

El promedio más conocido y utilizado en estadística

Media Aritmética — Definición

Suma de todos los valores dividida entre el número total de observaciones. Representa el "centro de gravedad" del conjunto de datos.

Fórmula — datos no agrupados

x̅ = Σxᵢ / n

x̅ = media muestral

Σxᵢ = suma de valores

n = total de datos

Ejemplo

Calificaciones: 7, 8, 9, 6, 10

x̅ = (7+8+9+6+10) / 5

x̅ = 8.0

Propiedades

• Única para cada conjunto de datos
• Sensible a valores extremos (outliers)
• Σ(xᵢ − x̅) = 0 siempre
• Solo aplica a variables cuantitativas

Media Ponderada

Cuando cada valor no tiene la misma importancia, se asigna un peso wᵢ que refleja su relevancia relativa.

x̅w = Σ(xᵢ·wᵢ) / Σwᵢ

Aplicaciones comunes:
• Calificación final con distintos porcentajes
• Índice de precios al consumidor
• Promedio ponderado de inversiones

Ejemplo — Calificación final del curso

Evaluación xᵢ wᵢ (%) xᵢ·wᵢ
Tareas 8.5 20 170
Exámenes Parciales 7.0 50 350
Examen Final 9.0 30 270
Total — 100 790

x̅w = 790 / 100 = 7.90

Media para Datos Agrupados

Fórmula

x̅ = Σ(mcᵢ·fᵢ) / n

mc = (Lᵢ + Ls) / 2 (marca de clase)

Se usa cuando los datos están en una tabla de distribución de frecuencias. Se usa la marca de clase como representante del intervalo.

Pasos:

1. Calcular mc de cada clase
2. Multiplicar mc · fᵢ de cada clase
3. Sumar todos los mc · fᵢ
4. Dividir entre n

Ejemplo — Calificaciones (n = 30)

Clase [Lᵢ – Ls) mc fᵢ mc · fᵢ
45 – 5449.53148.5
54 – 6358.55292.5
63 – 7267.58540.0
72 – 8176.57535.5
81 – 9085.55427.5
90 – 9994.52189.0
Total — 30 2 133.0

x̅ = 2 133 / 30 = 71.1 puntos

Tema 2.2

Mediana

El valor que divide al conjunto en dos mitades iguales

Mediana — Datos No Agrupados

Paso 1: Ordenar los datos de menor a mayor.
Paso 2: Localizar el valor central.

n impar

Me = x₁₆₋₀₎₁₂₂

Me = xₚ₆ₙₖₕ

posición (n+1)/2

n par

Me = (xₚ₆ₙₖₕ + xₚ₆ₙₖₕ₊₁) / 2

promedio de posiciones n/2 y (n/2)+1

La mediana no se ve afectada por valores extremos. Es preferible cuando hay datos atípicos.

Ejemplo n = 7 (impar)

Datos: 9, 3, 7, 5, 8, 2, 6

Ordenados: 2, 3, 5, 6, 7, 8, 9

Posición: (7+1)/2 = 4

Me = 6

Ejemplo n = 6 (par)

Datos: 4, 8, 1, 9, 3, 7

Ordenados: 1, 3, 4, 7, 8, 9

Posiciones 3 y 4

Me = (4 + 7) / 2 = 5.5

Mediana — Datos Agrupados

Fórmula de interpolación

Me = L + [(n/2 − F) / f] · c

L = límite inferior de la clase mediana

n = total de datos

F = frecuencia acumulada ANTES de la clase mediana

f = frecuencia de la clase mediana

c = amplitud de clase

Cómo localizar la clase mediana

1. Calcular n/2
2. La clase mediana es aquella donde la frecuencia acumulada F supera n/2 por primera vez

Ejemplo — Calificaciones (n = 30, n/2 = 15)

Clase fᵢ Fᵢ
45 – 5433
54 – 6358
63 – 72816← clase Me (F ≥ 15)
72 – 81723
81 – 90528
90 – 99230

L=63, n/2=15, F=8, f=8, c=9

Me = 63 + [(15−8)/8]·9 = 63 + 7.88 = 70.9

Tema 2.3

Moda

El valor que aparece con mayor frecuencia en el conjunto

Moda — Tipos y Definición

La moda (Mo) es el valor que tiene la mayor frecuencia absoluta. Es la única medida que puede aplicarse a variables cualitativas y cuantitativas.

Datos no agrupados — Ejemplos

Unimodal: 2, 3, 3, 4, 5 → Mo = 3

Bimodal: 1, 2, 2, 3, 4, 4, 5 → Mo = 2 y 4

Multimodal: varios valores con la misma f máxima

Amodal: 1, 2, 3, 4, 5 → no existe moda

Unimodal

Un único valor con la mayor frecuencia

3, 3, 3, 4, 5

Mo = 3

Bimodal

Dos valores con la misma frecuencia máxima

2, 2, 4, 4, 5

Mo = 2 y 4

Ventajas de la Moda

• No requiere cálculo aritmético
• Única aplicable a datos cualitativos
• No se ve afectada por valores extremos
• Puede ser múltiple

Ejemplo cualitativo: Derecho×12, Psicología×8, Administración×15, Criminología×6 → Mo = Administración

Moda — Datos Agrupados (Czuber)

Fórmula de Czuber

Mo = L + [d₁ / (d₁+d₂)] · c

L = límite inferior de la clase modal

d₁ = f modal − f de la clase anterior

d₂ = f modal − f de la clase siguiente

c = amplitud de clase

Clase modal

Es la que tiene la mayor frecuencia absoluta (fᵢ máxima) en la tabla de distribución.

Ejemplo — Calificaciones (n = 30)

Clase fᵢ Nota
45 – 543—
54 – 635f anterior a la modal
63 – 728Clase modal (f máxima)
72 – 817f siguiente a la modal
81 – 905—
90 – 992—

d₁ = 8−5 = 3  |  d₂ = 8−7 = 1  |  L = 63  |  c = 9

Mo = 63 + [3/(3+1)]·9 = 63 + 6.75 = 69.75

Tema 2.4

Análisis Comparativo

¿Cuándo usar cada medida de tendencia central?

¿Cuándo usar cada medida?

Medida Nivel de medición Úsala cuando… Evítala si…
Media
x̅		 Intervalo o Razón Distribución simétrica, sin outliers. Necesitas el total o comparar grupos. Hay datos extremos que distorsionan el promedio.
Mediana
Me		 Ordinal, Intervalo o Razón Distribución sesgada o con outliers. Ej: salarios, precios de casas. Se requiere operar algebraicamente con el resultado.
Moda
Mo		 Nominal, Ordinal, Intervalo o Razón Variable cualitativa o cuando importa el valor más típico/frecuente. La distribución es amodal o se necesita un valor único representativo.

Medidas y Sesgo de la Distribución

Distribución Simétrica

Las tres medidas coinciden

Sesgo Positivo (derecha)

Mo < Me < x̅ — Cola derecha

Sesgo Negativo (izquierda)

x̅ < Me < Mo — Cola izquierda

Ejemplo Integrador — Las Tres Medidas

Edades de 11 empleados: 22, 25, 28, 28, 30, 32, 35, 38, 40, 45, 72

Media x̅

Σxᵢ = 22+25+28+28+30+32+35+38+40+45+72

Σxᵢ = 395

x̅ = 395 / 11 = 35.9 años

El valor 72 "jala" la media hacia arriba. ¿Representa bien al grupo?

Mediana Me

n = 11 (impar) → posición (11+1)/2 = 6

22, 25, 28, 28, 30, 32, 35, 38, 40, 45, 72

Me = 32 años

No se ve afectada por 72. Más representativa para este conjunto.

Moda Mo

El valor 28 aparece 2 veces (el más frecuente)

Mo = 28 años

La edad más común. Distribución con sesgo positivo por el outlier 72.

Conclusión: Mo(28) < Me(32) < x̅(35.9) confirma sesgo positivo. La mediana es la medida más adecuada.

Síntesis — Unidad 2

Media x̅

Simple: x̅ = Σxᵢ/n · Ponderada: Σ(xᵢ·wᵢ)/Σwᵢ · Agrupada: Σ(mc·fᵢ)/n. Sensible a outliers. Nivel intervalo/razón.

Mediana Me

Sin agrupar: valor en posición (n+1)/2 o promedio de los dos centrales. Agrupada: L+[(n/2−F)/f]·c. Robusta ante outliers.

Moda Mo

Sin agrupar: valor más frecuente. Agrupada (Czuber): L+[d₁/(d₁+d₂)]·c. Única medida aplicable a nivel nominal.

Sesgo y elección

Simétrica: x̅ = Me = Mo. Sesgo positivo: Mo < Me < x̅. Sesgo negativo: x̅ < Me < Mo. Elegir según contexto y tipo de variable.
