Programación Visual · Práctica 1

Interfaces gráficas con Python e integración con análisis de datos

Explora Tkinter, PyQt y Kivy, construye una ventana paso a paso y conecta una interfaz con pandas y matplotlib para analizar datos.

⏱ Duración sugerida: 2 horas🧩 7 actividades💻 Nivel: introductorio

Objetivo y datos del alumno

Al terminar podrás elegir un framework de GUI para un proyecto, construir una ventana con widgets y mostrar en ella resultados de un análisis de datos.

Resultados de aprendizaje

  • Comparar Tkinter, PyQt y Kivy según el tipo de aplicación.
  • Explicar el ciclo de una GUI: crear widgets, acomodarlos (layout) y entrar al bucle de eventos.
  • Cargar un CSV con pandas, agrupar y resumir datos.
  • Incrustar una gráfica de matplotlib dentro de una ventana Tkinter.
Cómo se trabaja: las actividades 1 a 5 y la 7 se resuelven aquí mismo, en el navegador. La actividad 6 te entrega un programa completo para ejecutar en tu computadora. Al final generas tu archivo de evidencia.

Cómo está organizado

  
    
    
  • Clase Analizador(tk.Tk): la ventana principal es un objeto; sus widgets son atributos (self.tabla, self.lienzo).
    • 
    
  • Callbacks: command=self.abrir_csv conecta el botón con un método. Sin paréntesis: se pasa la función, no se ejecuta.
    • 
    
  • Separación: la interfaz (_construir_interfaz) y la lógica de datos (abrir_csv, graficar) están en métodos distintos.
    • 
    
  • matplotlib en Tkinter: se usa Figure + FigureCanvasTkAgg, nunca plt.show().
