2. La idea del simplex en 1 minuto

Imagina que todas las soluciones posibles forman una figura con esquinas (la región factible). El mejor resultado siempre está en una esquina. El simplex camina de esquina en esquina, siempre mejorando, hasta que ya no puede mejorar.

En el Problema 1, el simplex empieza en (0,0) con Z=0, sube a (0,6) con Z=30 y termina en (2,6) con Z=36. ¡Solo 2 pasos!

El algoritmo (así lo programarás)

Cómo se ve la tabla

  • h₁, h₂, h₃ son variables de holgura: lo que sobra de cada recurso.
  • La fila Z lleva los coeficientes de la ganancia con signo negativo (−c).
  • Los números negativos de la fila Z dicen: «todavía puedo ganar más».

3. Maximizar: Problema 1

Fábrica de puertas y ventanas

Una fábrica produce puertas (x₁) y ventanas (x₂). Gana $3 por puerta y $5 por ventana. Capacidad: máximo 4 puertas, máximo 6 ventanas (cada una usa 2 unidades del taller de 12) y 18 horas de ensamble (puerta 3 h, ventana 2 h).

Modelo: maximizar Z = 3x₁ + 5x₂  sujeto a  x₁ ≤ 4 · 2x₂ ≤ 12 · 3x₁ + 2x₂ ≤ 18 · x₁, x₂ ≥ 0

2

Construye la tabla inicial

Dentro de una función simplex_max(c, A, b) arma la matriz T con numpy:

Python
import numpy as np

def simplex_max(c, A, b, mostrar=True):
    c = np.array(c, dtype=float)
    A = np.array(A, dtype=float)
    b = np.array(b, dtype=float)
    m, n = A.shape                          # m restricciones, n variables

    T = np.zeros((m + 1, n + m + 1))        # tabla llena de ceros
    T[:m, :n]    = A                        # tus restricciones
    T[:m, n:n+m] = np.eye(m)                # holguras (matriz identidad)
    T[:m, -1]    = b                        # lado derecho
    T[m, :n]     = -c                       # fila Z con signo negativo
    base = list(range(n, n + m))            # al inicio las holguras son básicas
💡 Pista

np.eye(3) crea una matriz 3×3 con unos en la diagonal. T[:m, -1] es la última columna sin la fila Z.

Imprime la tabla con print(np.round(T, 3)). Debe verse así:

Elige la columna pivote

Es la columna con el número más negativo de la fila Z. Si no hay negativos, ya terminaste.

Python
    fila_z = T[m, :-1]                      # fila Z sin la columna b
    if np.all(fila_z >= -1e-9):             # ¿ya no hay negativos?
        pass                                # TODO: sal del ciclo (break)
    col = int(np.argmin(fila_z))            # posición del más negativo

Aquí fila_z = [-3, -5, 0, 0, 0], entonces col = 1 (entra x₂).

4

Elige la fila pivote (prueba del cociente)

Divide cada b entre el número de la columna pivote, solo si ese número es positivo. La fila con el cociente más pequeño es la que sale.

Python
    cocientes = np.full(m, np.inf)          # infinito = "no aplica"
    for i in range(m):
        if T[i, col] > 1e-9:
            cocientes[i] = T[i, -1] / T[i, col]
    # TODO: si todos son infinito el problema es NO ACOTADO -> avisa con raise ValueError

💡 Pista

Divide por cero no se permite: por eso solo calculamos cuando el valor de la columna es mayor que 0.

5

Pivotea (el corazón del método)

Haz que el pivote valga 1 y todo lo demás de su columna valga 0:

Python
    T[fila] = T[fila] / T[fila, col]        # el pivote queda en 1
    for i in range(m + 1):                  # todas las filas, incluida la Z
        if i != fila:
            T[i] = T[i] - T[i, col] * T[fila]
    base[fila] = col                        # la variable que entra ocupa su lugar
Es lo mismo que hacías en álgebra con operaciones entre renglones (Gauss-Jordan).
6

Haz que se repita (ciclo while) y devuelve el resultado

Pon los pasos 3 al 5 dentro de un while True:. Al terminar lee la solución:

Python
    x = np.zeros(n + m)
    for i, j in enumerate(base):
        x[j] = T[i, -1]                     # las básicas valen su b
    precios_sombra = T[m, n:n+m]            # fila Z bajo las holguras
    return x[:n], T[m, -1], precios_sombra
💡 Pista

Ordena así: dentro del while imprime la tabla, revisa si es óptima (break), calcula columna, calcula fila, pivotea.

4. Minimizar con el método dual

El simplex de tabla que programaste resuelve maximizar con restricciones ≤. Para minimizar con restricciones ≥ (por ejemplo, costos con requisitos mínimos) usamos un truco: resolver el problema dual, que sí es de maximizar. Tu misma función sirve.

Problema 3: Mezcla de alimento para ganado

Se mezclan dos ingredientes. El ingrediente A cuesta $12 por kg y el B $20. La mezcla debe aportar al menos 100 unidades de proteína (A aporta 6, B aporta 8) y al menos 120 unidades de energía (A aporta 7, B aporta 12). ¿Cuántos kg de cada uno para gastar lo menos posible?

Primal: min Z = 12x₁ + 20x₂  s.a.  6x₁ + 8x₂ ≥ 100 · 7x₁ + 12x₂ ≥ 120 · x ≥ 0

Dual: max W = 100y₁ + 120y₂  s.a.  6y₁ + 7y₂ ≤ 12 · 8y₁ + 12y₂ ≤ 20 · y ≥ 0

1

Programa simplex_min

Solo transpones A e intercambias b con c:

Python
def simplex_min(c, A, b, mostrar=True):
    A = np.array(A, dtype=float)
    y, w, precios = simplex_max(b, A.T, c, mostrar)   # resuelve el DUAL
    return precios, w, y                              # x* = precios sombra del dual
Ojo: el orden es simplex_max(b, A.T, c) — la «ganancia» del dual es b y los «recursos» son c.

     [7, 12]]
b = [100, 120]

x, z, y = simplex_min(c, A, b)

5. Verifica con scipy

Un buen ingeniero comprueba su resultado. La librería scipy trae un solucionador profesional. Compara tu respuesta con la suya:

Python
from scipy.optimize import linprog

# MAXIMIZAR: linprog minimiza, así que cambia el signo de c
r = linprog([-3, -5], A_ub=[[1,0],[0,2],[3,2]], b_ub=[4,12,18])
print("MAX  x =", r.x, " Z =", -r.fun)

# MINIMIZAR con >= : multiplica por -1 las restricciones para dejarlas en <=
r = linprog([12, 20], A_ub=[[-6,-8],[-7,-12]], b_ub=[-100,-120])
print("MIN  x =", r.x, " Z =", r.fun)
Salida esperada
MAX  x = [2. 6.]  Z = 36.0
MIN  x = [15.    1.25]  Z = 205.0
Regla de oro: si tu simplex y linprog dan lo mismo, tu programa está bien. Si no coinciden, revisa el signo de la fila Z, el orden de (b, A.T, c) y la prueba del cociente.
