Guía de consulta de Tkinter

Escribe lo que buscas (por ejemplo «tabla», «grid», «json») o elige una categoría. Cada ejemplo tiene botón para copiar.

tk.Tk()

Crea la ventana principal. Solo debe haber una.
import tkinter as tk
ventana = tk.Tk()
ventana.title('Mi app')
ventana.geometry('600x400')   # ancho x alto
ventana.minsize(500, 300)
ventana.resizable(True, True)
ventana.mainloop()           # SIEMPRE al final

Programación con clase

Para proyectos grandes, la ventana es una clase. Así todo queda ordenado y los métodos comparten datos con self.
class App(tk.Tk):
    def __init__(self):
        super().__init__()
        self.title('Mi app')
        self.datos = []

if __name__ == '__main__':
    App().mainloop()

Métodos de la ventana

title() título · geometry() tamaño · after(ms, f) ejecuta f después de ms · destroy() cierra · protocol('WM_DELETE_WINDOW', f) qué hacer al cerrar con la X · focus_set() pone el cursor · update() refresca · configure(bg='#fff') cambia opciones.

tk.Frame / ttk.Frame

Caja contenedora para agrupar widgets.
marco = ttk.Frame(ventana, padding=10)
marco.pack(fill='both', expand=True)

ttk.LabelFrame

Marco con título.
grupo = ttk.LabelFrame(ventana, text='Datos')

ttk.Label

Texto o imagen. Para cambiarlo después: etiqueta.config(text='...') o usa textvariable.
ttk.Label(ventana, text='Nombre:').pack()

ttk.Button

Botón. command recibe la función SIN paréntesis.
ttk.Button(ventana, text='Guardar', command=self.guardar).pack()

ttk.Entry

Una línea de texto. get() lee, delete(0,'end') borra, insert(0,'hola') escribe, show='*' oculta.
e = ttk.Entry(ventana, textvariable=self.v_nombre)
valor = e.get()

tk.Text

Texto de varias líneas. Los índices son '1.0' (inicio) y 'end'.
t = tk.Text(ventana, height=4, width=40)
texto = t.get('1.0', 'end').strip()
t.delete('1.0', 'end')
t.insert('end', 'Hola')

ttk.Combobox

Lista desplegable. state='readonly' impide escribir.
c = ttk.Combobox(ventana, values=['A','B'], state='readonly', textvariable=self.v_cat)

ttk.Checkbutton

Casilla (verdadero/falso). Usa BooleanVar.
ttk.Checkbutton(ventana, text='Acepto', variable=self.v_acepto)

ttk.Radiobutton

Una opción entre varias. Todas comparten la misma variable.
for t in ('Nuevo','Usado'):
    ttk.Radiobutton(ventana, text=t, value=t, variable=self.v_estado).pack()

ttk.Spinbox / ttk.Scale

Número con flechas / deslizador.
ttk.Spinbox(ventana, from_=10, to=16, textvariable=self.v_tam)
ttk.Scale(ventana, from_=0, to=100, orient='horizontal')

tk.Listbox

Lista simple. insert('end', x), curselection(), delete(0,'end').
lb = tk.Listbox(ventana)
lb.insert('end', 'Elemento')
indices = lb.curselection()

ttk.Treeview

Tabla. Es el widget clave de un catálogo.
t = ttk.Treeview(f, columns=('a','b'), show='headings')
t.heading('a', text='Artículo')
t.insert('', 'end', iid='1', values=('Libro','Usado'))
fila = t.selection()          # tupla de iids
t.delete(*t.get_children())  # vaciar

ttk.Notebook

Pestañas.
nb = ttk.Notebook(ventana)
p1 = ttk.Frame(nb)
nb.add(p1, text='Inicio')
nb.select(p1)

ttk.Scrollbar

Barra de desplazamiento; se conecta en los dos sentidos.
barra = ttk.Scrollbar(f, command=tabla.yview)
tabla.configure(yscrollcommand=barra.set)

tk.Toplevel

Ventana secundaria.
v = tk.Toplevel(self)
v.title('Detalle')
v.transient(self)

tk.Menu

Barra de menú.
barra = tk.Menu(self)
arch = tk.Menu(barra, tearoff=0)
arch.add_command(label='Salir', command=self.destroy)
barra.add_cascade(label='Archivo', menu=arch)
self.config(menu=barra)

tk.Canvas

Dibujar formas y gráficos.
c = tk.Canvas(ventana, width=300, height=200, bg='white')
c.create_rectangle(10,10,100,60, fill='gold')
c.create_text(150,100,text='Hola')

ttk.Progressbar / ttk.Separator

Barra de avance / línea divisoria.
ttk.Progressbar(ventana, maximum=100, value=40)
ttk.Separator(ventana, orient='horizontal').pack(fill='x')

pack()

Apila widgets uno tras otro. Rápido para cosas simples.
w.pack(side='left', fill='x', expand=True, padx=8, pady=4)

grid()

Acomoda en filas y columnas: ideal para formularios. No mezcles pack y grid en el mismo contenedor.
f.columnconfigure(1, weight=1)   # la columna 1 se estira
ttk.Label(f, text='Nombre:').grid(row=0, column=0, sticky='w')
ttk.Entry(f).grid(row=0, column=1, sticky='ew')   # sticky: n s e w

place()

Posición exacta en píxeles. Evítalo salvo casos especiales.
w.place(x=20, y=30)

Estilos y tema

Cambian la apariencia de todos los widgets ttk.
estilo = ttk.Style(self)
estilo.theme_use('clam')
estilo.configure('.', font=('Arial', 11))
estilo.configure('Acento.TButton', font=('Arial', 11, 'bold'))
ttk.Button(self, text='OK', style='Acento.TButton')

state() de ttk

Activa o desactiva un widget ttk.
e.state(['disabled'])    # desactivar
e.state(['!disabled'])   # activar
e.instate(['disabled'])  # ¿está desactivado?

StringVar, IntVar, BooleanVar

Variables de control: el widget y tu código leen y escriben el mismo dato.
v = tk.StringVar(value='hola')
v.set('adiós')
dato = v.get()
v.trace_add('write', lambda *a: print(v.get()))  # se ejecuta al cambiar

self.bind('<Control-n>', self.nuevo)
self.bind('<Return>', self.guardar)
c.bind('<<ComboboxSelected>>', self.filtrar)

def ver_detalle(self, evento=None):   # evento=None permite usarla también con un botón
    ...

Guardar con JSON

Convierte tu lista de diccionarios en un archivo.
import json
with open('datos.json', 'w', encoding='utf-8') as f:
    json.dump(self.articulos, f, ensure_ascii=False, indent=2)

Cargar con JSON

Revisa que exista y protege con try.
import os
if os.path.exists('datos.json'):
    try:
        with open('datos.json', encoding='utf-8') as f:
            self.articulos = json.load(f)
    except (OSError, json.JSONDecodeError):
        self.articulos = []

Patrón: lista de diccionarios + tabla

Los datos viven en la lista; la tabla solo los muestra. Después de cambiar la lista, llama a refrescar(), que borra la tabla y la vuelve a llenar.
