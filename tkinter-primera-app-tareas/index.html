Tu primera aplicación completa

Ya practicaste ventanas, Label, Entry, Button, pack, grid, place, eventos, Listbox, Combobox, Checkbutton, Radiobutton y messagebox en la Semana 6. Ahora vas a usar todo eso, paso a paso, para construir un proyecto nuevo desde cero: una aplicación que funciona de verdad y que puedes enseñar a otras personas.

Tu aplicación: «Mi lista de tareas»

  • Escribes una tarea y la agregas con un botón o con Enter.
  • Ves todas tus tareas en una lista.
  • Marcas una tarea como hecha (✔) o la eliminas.
  • Ves cuántas tareas llevas, hechas y pendientes.
  • Al cerrar se guarda en un archivo; al abrir, regresa todo.
Así se verá al terminar.
Lo que entregas: un solo archivo de Python llamado tareas_TuApellido.py que abra sin errores y haga todo lo anterior. Usa tu propio código: puedes copiar de la guía para no cometer errores de escritura, pero lee cada línea y personaliza tu aplicación.

Entiende el código:

  • tk.Frame(ventana) crea la caja de la zona 1 y grid(row=1…) la coloca en la fila 1 de la ventana.
  • sticky="ew" estira el widget hacia este (e) y oeste (w): ocupa todo el ancho.
  • columnconfigure(0, weight=1) hace que el campo se estire y el botón conserve su tamaño.

Tu primera función: agregar una tarea12 min

Ahora la ventana hará algo. Primero escribe la función que actualiza el contador (se usará varias veces), y después agregar. Ambas van debajo de # ---------- FUNCIONES ----------.

Python · tareas_Apellido.py
def actualizar_contador():
    total = lista.size()                      # cuántas tareas hay
    hechas = 0
    for t in lista.get(0, tk.END):            # recorre todas las tareas
        if t.startswith("✔ "):                # ¿empieza con la palomita?
            hechas = hechas + 1
    estado.config(text=f"Tareas: {total}  |  Hechas: {hechas}  |  Pendientes: {total - hechas}")
Python · tareas_Apellido.py
def agregar(evento=None):
    texto = entrada.get().strip()             # lee lo escrito y quita espacios sobrantes
    if texto == "":                           # ¿está vacío?
        messagebox.showwarning("Falta información", "Escribe una tarea antes de agregarla.")
        entrada.focus_set()
        return                                # se detiene aquí
    lista.insert(tk.END, texto)               # agrega al final de la lista
    entrada.delete(0, tk.END)                 # limpia el campo
    entrada.focus_set()                       # el cursor regresa al campo
    actualizar_contador()

Marcar como hecha y eliminar10 min

Estas funciones trabajan con la tarea que el usuario selecciona. Agrégalas debajo de las anteriores.

Python · tareas_Apellido.py
def tarea_elegida():
    seleccion = lista.curselection()          # posición de la tarea seleccionada
    if not seleccion:                         # no hay ninguna seleccionada
        messagebox.showinfo("Elige una tarea", "Primero haz clic en una tarea de la lista.")
        return None
    return seleccion[0]


def marcar(evento=None):
    i = tarea_elegida()
    if i is None:
        return
    texto = lista.get(i)
    if texto.startswith("✔ "):
        nuevo = texto[2:]                     # quita la palomita
    else:
        nuevo = "✔ " + texto                  # pone la palomita
    lista.delete(i)
    lista.insert(i, nuevo)
    lista.selection_set(i)                    # vuelve a seleccionar la tarea
    actualizar_contador()


def eliminar(evento=None):
    i = tarea_elegida()
    if i is None:
        return
    if messagebox.askyesno("Eliminar tarea", f"¿Seguro que quieres eliminar esta tarea?\n\n{lista.get(i)}"):
        lista.delete(i)
        actualizar_contador()

Conecta los botones de la Zona 3 (agrega el command a cada uno):

Python · cambia estas dos líneas
boton_marcar = tk.Button(marco_botones, text="Marcar / Desmarcar", font=FUENTE, command=marcar)
boton_eliminar = tk.Button(marco_botones, text="Eliminar", font=FUENTE, command=eliminar)
  • tarea_elegida() es una función auxiliar: la usan marcar y eliminar, así no repetimos código.
  • Para «marcar» agregamos «✔ » al inicio del texto. El contador cuenta las tareas que empiezan así.
  • askyesno pregunta «Sí/No» y devuelve True si el usuario acepta.
▶ Ejecuta y comprueba: agrega 3 tareas, selecciona una y pulsa Marcar / Desmarcar (aparece ✔ y el contador cambia). Pulsa Eliminar: pide confirmación. Sin seleccionar nada, debe avisar.
¿Dice «NameError: actualizar_contador»? Verifica que escribiste esa función en el paso 5 y que está arriba de la sección VENTANA.

Guardar y cargar con un archivo8 min

Hasta ahora, al cerrar la ventana las tareas se pierden. Vamos a guardarlas en un archivo de texto (tareas.txt).

Python · tareas_Apellido.py
def guardar():
    with open(ARCHIVO, "w", encoding="utf-8") as f:     # "w" = escribir (crea o reemplaza)
        for t in lista.get(0, tk.END):
            f.write(t + "\n")


def cargar():
    try:
        with open(ARCHIVO, "r", encoding="utf-8") as f:  # "r" = leer
            for linea in f:
                linea = linea.rstrip("\n")
                if linea != "":
                    lista.insert(tk.END, linea)
    except FileNotFoundError:                            # la primera vez no existe el archivo
        pass


def salir():
    guardar()                                            # guarda antes de cerrar
    ventana.destroy()

Conecta el botón Salir:

Python · cambia esta línea
boton_salir = tk.Button(marco_botones, text="Salir", font=FUENTE, command=salir)
  • with open(...) abre el archivo y lo cierra solo al terminar.
  • encoding="utf-8" permite guardar acentos, ñ y la palomita ✔ sin errores.
  • try / except FileNotFoundError: la primera vez el archivo todavía no existe, y eso no es un error del programa.
